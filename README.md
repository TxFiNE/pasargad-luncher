# Pasargad Launcher

لانچر و رابط کاربری تیم پاسارگاد برای دسترسی به سرورها و ابزارهای مرتبط با Counter-Strike.

## وضعیت فعلی مخزن

این مخزن در حال حاضر شامل رابط کاربری وب در فایل `index.html` است. این فایل به‌تنهایی یک بستهٔ دسکتاپ قابل نصب نیست. قابلیت‌هایی مانند تشخیص وضعیت بازی، اجرای مستقیم بازی، مدیریت فایل‌های CFG و کنترل پنجره به API سمت Electron با نام `window.pasargad` نیاز دارند.

## پیش‌نمایش

برای دیدن رابط کاربری، فایل `index.html` را در مرورگر باز کنید. در حالت مرورگر، بخش‌هایی که به Electron یا نصب محلی بازی نیاز دارند در دسترس نخواهند بود. اتصال به سرور از طریق پروتکل Steam به نصب بودن Steam وابسته است.

## قابلیت‌های رابط کاربری

- صفحهٔ کتابخانه و وضعیت بازی
- فهرست سرورهای پاسارگاد (با مقدار پیش‌فرض داخلی)
- صفحهٔ CS:S v34 برای انتخاب کلاینت محلی
- نمایش اخبار
- رابط مدیریت CFG و تنظیمات اجرا
- طراحی واکنش‌گرا با زبان فارسی

## دادهٔ سرورها

در صورت وجود فایل `servers.json`، رابط کاربری تلاش می‌کند فهرست سرورها و اخبار را از آن بخواند. اگر فایل در دسترس نباشد، سرور پیش‌فرض داخل رابط استفاده می‌شود.

نمونهٔ ساختار:

```json
{
  "servers": [
    {
      "name": "PASARGAD Main",
      "ip": "46.38.138.143",
      "port": 22000,
      "mode": "Competitive"
    }
  ],
  "news": []
}
```

## مشارکت و توسعه

برای انتشار نسخهٔ دسکتاپ، فایل‌های اصلی Electron (از جمله `main.js`، `preload.js` و `package.json`) و پیاده‌سازی امن API مورد استفادهٔ رابط باید به مخزن اضافه و جداگانه آزمایش شوند. تا آن زمان، این مخزن را نسخهٔ رابط کاربری وب در نظر بگیرید.
