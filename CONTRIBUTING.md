# Contributing / مشارکت

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. `npm install` then `npm start` to test
3. Keep changes small and focused; follow the existing code style
4. Use clear commit messages (`feat:`, `fix:`, `docs:` …)
5. Open a Pull Request describing what and why

For bugs and ideas, open an issue first using the templates.
